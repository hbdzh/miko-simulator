# 键位映射

手柄面板通过 macOS GameController 显示系统提供的电源状态；系统或手柄未提供电量时显示「电量不可用」。

原生直通时，主控和同步跟随端优先使用 Android `uinput`，将游戏的震动启停反馈给绑定手柄；缺少 `uinput` 时回退到不支持震动的 `hid`。震动和电量依赖手柄及系统支持，实际兼容性尚待实机验证；单次连续震动最长 10 秒。

打开播放器的键位编辑，先选择单点、连点、滑动、录制手势、射击视角、技能瞄准或运行脚本，再点击画面放置并按键绑定；方向摇杆直接点击画面放置。运行脚本需要先保存录制，放置时默认关联第一个脚本，之后可修改。选择「无」可暂时停止放置和修改键位，直接操作模拟器画面；侧栏和未保存的修改会保留。选中已有键位后，在侧栏的「按键行为」中选择：

- **按住触碰**：按下键时触碰，松开时释放。
- **切换长按**：按一次保持触碰，再按一次释放。
- **按住连点 / 切换连点**：分别在按住期间或两次按键之间连点；间隔可设置为 40～5000 毫秒。
- **滑动**：从键位所在位置滑向指定终点，可设置终点的屏幕相对坐标及持续时间。
- **录制手势**：选择「录制轨迹」后，在屏幕上按住并拖动，松开结束。轨迹使用相对于当前显示方向的坐标，最多记录 1024 个采样点和 10 秒。
- **射击视角**：选择视角触点并绑定切换键，按键后捕获鼠标，鼠标移动驱动视角；再次按键释放鼠标。可调整灵敏度和触控范围。
- **技能瞄准**：在技能按钮上绑定按键，按住后移动鼠标瞄准，松键施放。右键或配置的额外取消键会将触点拖至取消位置后抬起；请根据游戏实际取消区域设置坐标。额外取消键在瞄准期间优先于同键的其他映射。
- **运行脚本**：为键位选择一个已保存的录制，按键后按该脚本的默认回放设置执行。

在方案管理中可将当前前台 Android 应用关联到当前方案；绑定会转移该应用原有的方案关联，系统桌面不能绑定。自动切换是全局开关。选择预设模板会覆盖当前方案的所有方向键位。手动切换方案会覆盖当前应用的自动选择，前台应用再次变化后恢复自动关联。编辑方案期间不会自动切换；关联可移除，自动切换也可关闭。

在播放器手柄面板选择「映射触控」并连接手柄，再打开键位编辑，点击画面后按下手柄按键或扳机即可绑定。动作沿用键位编辑器的按住、切换、连点、滑动、手势和脚本设置；左摇杆控制当前方向的第一个虚拟摇杆，右摇杆控制已启用的射击视角或按住的技能瞄准。技能取消键也可以选择手柄控件。原生直通和映射触控在同一设备上互斥。

映射触控由播放器处理，关闭播放器窗口会停止手柄捕获。事件丢失、心跳中断或输入失败时会停止捕获并尝试释放触点，需重新连接手柄。

手柄面板可按手柄型号和当前前台应用保存摇杆死区、灵敏度、X/Y 反转及扳机阈值，提供恢复默认设置。死区按 X、Y 轴分别计算。调校在下次连接手柄时生效；无前台应用时保存到该型号的默认配置。触控映射使用现有应用方案关联和自动切换，修改方案或失焦时释放已按下的触点。

保存方案后键位生效。窗口失焦、切换方向、停用映射或开始脚本回放时，播放器会停止定时输入并尝试释放已按下的触点。手动点击或输入普通按键会停止当前映射触点；手柄映射模式下会先停止接收手柄事件，再交接给手动输入。

设备输入注入失败时，播放器停止当前定时输入、尝试释放触点并显示错误；如果正在录制脚本，本次录制会停止，不会保存为成功的录制。设备断开或未响应时，无法保证设备实际收到释放事件。

CLI 或 MCP 正在控制同一设备时，播放器手动输入会请求接管：界面流程和手柄转发会停止，单次按键先完成按下和抬起；确认已有输入释放后才交接。若输入所有者异常退出或释放未确认，停止并重新启动设备后恢复输入。

不含高级行为的旧版方案仍可读取。滑动、手势和连点使用版本 2；射击视角与技能瞄准使用版本 3；引用脚本的方案使用版本 4；设置技能额外取消键的方案使用版本 5；手柄控件绑定使用版本 6。旧版 miko 不能读取不认识的版本，导出供旧版使用时应保留旧版方案。不同屏幕比例、方向或应用画面布局可能影响手势位置。
